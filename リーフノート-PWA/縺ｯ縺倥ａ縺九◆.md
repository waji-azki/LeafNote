# リーフノート アプリ版 セットアップ手順

このフォルダの中身を「自分のインターネット上の置き場所」に置くと、リーフノートがスマホのホーム画面から
アプリとして起動できるようになります。さらにGoogleドライブにつなぐと、スマホとパソコンで同じメモが使えます。

作業は全部で30分くらい、どれも一度きりです。**1と2だけでもアプリとしては使えます。**
Googleドライブの設定（4）は、あとから落ち着いてやっても大丈夫です。

## 入っているもの

| ファイル | 役割 |
| --- | --- |
| index.html | アプリ本体 |
| manifest.json | アプリの名前・アイコンの設定 |
| sw.js | 圏外でも開けるようにする仕組み |
| icon-192.png / icon-512.png / icon-maskable-512.png | アイコン |

6つ全部を、同じ場所にまとめて置いてください。

---

## 1. 置き場所を作る（GitHub Pages・無料）

アプリとしてインストールしたり、Googleにつないだりするには、`https://` で始まるアドレスが必要です。
GitHub Pagesなら無料で、広告も入りません。

1. [github.com](https://github.com) でアカウントを作ります（メールアドレスとパスワードだけ）。
2. 右上の「＋」→「New repository」を選びます。
3. **Repository name** に `leafnote` と入力。**Public** のまま「Create repository」。
4. 次の画面の「uploading an existing file」というリンクを押します。
5. このフォルダの6つのファイルを、まとめてドラッグ＆ドロップ（スマホなら「ファイルを選択」から6つ選ぶ）。
6. 下の「Commit changes」を押します。
7. 上のタブの「Settings」→ 左メニューの「Pages」。
8. **Source** を `Deploy from a branch`、**Branch** を `main` と `/ (root)` にして「Save」。
9. 1〜3分待つと、同じ画面に `https://（あなたのユーザー名）.github.io/leafnote/` というアドレスが出ます。

このアドレスがリーフノートの住所です。**あとで使うので、どこかに控えておいてください。**

> あとでアプリを新しくしたいときは、同じ場所に新しい `index.html` を上げ直すだけです。メモは消えません。

---

## 2. ホーム画面に追加する

1. 上のアドレスをスマホのChromeで開きます。
2. 右上の「⋮」→「ホーム画面に追加」（iPhoneのSafariなら、下の共有ボタン→「ホーム画面に追加」）。
3. ホーム画面に葉っぱのアイコンができます。

これでアドレスバーのない、アプリと同じ見た目で起動します。圏外でも開けますし、メモは端末の中に保存されます。

---

## 3. 今のメモを引っ越す

Claudeで使っていたリーフノートのメモを持ってくる手順です。**先にこれをやってください**（あとからだと、
新しく書いたメモと混ざります）。

1. Claude版のリーフノートを開き、下の「設定」→「エクスポート」。
   `leafnote-backup-〜.json` というファイルが保存されます。
2. アプリ版を開き、同じく「設定」→「インポート」。
3. さっきのファイルを選び、確認に「OK」。

メモ・カテゴリ・印刷の設定が、そのまま移ります。

---

## 4. Googleドライブにつなぐ

ここは少し手間ですが、一度やれば終わりです。
リーフノートがドライブにつくる `leafnote-data.json` という1つのファイルだけを読み書きします
（`drive.file` という権限で、**ドライブの他の中身はアプリから一切見えません**）。

### 4-1. プロジェクトを作る

1. [console.cloud.google.com](https://console.cloud.google.com) を開き、いつものGoogleアカウントでログイン。
2. 画面上のプロジェクト選択（「プロジェクトを選択」）→「新しいプロジェクト」。
3. プロジェクト名に `leafnote` と入れて「作成」。作ったプロジェクトを選んでおきます。

### 4-2. Drive APIを使えるようにする

1. 左メニュー →「APIとサービス」→「ライブラリ」。
2. `Google Drive API` を検索して開き、「有効にする」。

### 4-3. アプリの情報を登録する

1. 左メニュー →「Google Auth Platform」→「ブランディング」→「始める」。
2. **アプリ名**：`リーフノート`、**ユーザーサポートメール**：自分のメールアドレス。
3. **対象**：「外部」を選びます。
4. **連絡先情報**：自分のメールアドレス。
5. 規約に同意して「作成」。
6. 左の「対象」→「テストユーザー」→「ユーザーを追加」で、**自分のGmailアドレスを追加**して保存。
   これを忘れると、あとで接続できません。

> 「データアクセス」でスコープを追加する必要はありません。アプリ側から指定します。

### 4-4. クライアントIDを作る

1. 左の「クライアント」→「クライアントを作成」。
2. **アプリケーションの種類**：`ウェブアプリケーション`。
3. **名前**：`リーフノート`。
4. **承認済みのJavaScript生成元** →「URIを追加」に、1で控えたアドレスの**ドメインだけ**を入れます。

   ```
   https://（あなたのユーザー名）.github.io
   ```

   `/leafnote/` などのパスや、最後の `/` は付けないでください。ここが合っていないと接続できません。
5. **承認済みのリダイレクトURI** は空のままで大丈夫です。
6. 「作成」を押すと、`000000-xxxxxxxx.apps.googleusercontent.com` という文字列が出ます。これをコピー。

### 4-5. アプリに貼る

1. リーフノートを開き、「設定」→「Googleドライブ同期」。
2. コピーしたクライアントIDを貼り付けて「Googleドライブに接続」。
3. Googleのログイン画面が出ます。**「このアプリはGoogleで確認されていません」**と表示されたら、
   「詳細」→「リーフノート（安全ではないページ）に移動」を選んでください。
   自分で作った自分のためのアプリなので問題ありません。
4. 「Googleドライブのこのアプリで使用するファイルの表示、編集…」に許可を出します。
5. 「同期済み」と出たら完了です。

### つながったあとの動き

- メモを書き換えると、手が止まって5秒ほどでドライブに保存されます。
- アプリを開いたとき、別の端末に切り替えたときに、ドライブから読み込みます。
- すぐ合わせたいときは「今すぐ同期」。
- 圏外のときはそのまま書けて、つながったときにまとめて送られます。
- 同じメモを2台で同時に直した場合は、**あとに直したほうが残ります**。消したメモは復活しません。

もう一台の端末でも使うときは、その端末でも 1のアドレスを開いて、同じクライアントIDを貼るだけです。

## 5. 困ったとき

**「クライアントIDの形式が違うようです」と出る**
　末尾が `.apps.googleusercontent.com` になっているか確認してください。前後の空白も混ざりやすいです。

**「アクセスが許可されていません」と出る**
　4-3の「テストユーザー」に自分のアドレスが入っているか、4-4の生成元がアドレスのドメインと
　ぴったり同じか（`https://` あり、末尾 `/` なし）を見直してください。

**「Googleへの接続が必要です」と出たまま**
　ブラウザがポップアップをふさいでいることがあります。「今すぐ同期」を自分で押すと出てきます。

**アプリを新しくしたのに変わらない**
　一度アプリを閉じて開き直してください。それでも変わらないときは、ブラウザで同じアドレスを開いて
　更新すると新しくなります。

**メモが消えてしまった**
　「設定」→「エクスポート」でときどきバックアップを取っておくと安心です。
　ドライブにつないでいる場合は、ドライブの `leafnote-data.json` が最新の控えになります。
